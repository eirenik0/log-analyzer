# Analysis contracts

These specifications define evidence identity, lifecycle semantics, report bounds and profile validation. See [[usage]] for ordinary investigation and [[contract-fixtures]] for synthetic contract examples.

- [[evidence-contract]] — source identity, references, coverage and redaction.
- [[event-classification]] — explicit event rules and lifecycle semantics.
- [[investigation-contract]] — findings, retained artifacts and retrieval.
- [[bounded-reports]] — budgets, ordering and reconstruction.
- [[profile-validation]] — independent expected facts and profile suitability.
